# Аллокация по долям дней без стокаута

Дата: 2026-07-20. Offline-эксперимент, production не изменялся.

## Метод

Для каждой пары «пекарня–SKU» доля рассчитывалась только по прошлым
подтверждённым дням без стокаута. Новая доля смешивалась с исходной через
shrinkage, после чего все доли нормализовались. Общая сумма прогнозов каждого
исследуемого bakery-day сохранялась с машинной точностью.

Проверены профили с днём недели и без него, окна 28/56 дней, минимум 2/3
наблюдения и prior 3/7/14 дней. Это исследовательская аллокация внутри набора
SKU с надёжной классификацией, а не полный production allocator.

## Результат

Вариант с днём недели имел слишком низкое покрытие. Его лучший сценарий
устранил 31 старый недопрогноз, создал 10 новых и увеличил суммарный дефицит с
1 530,3 до 1 555,2 единицы.

Fallback без дня недели поднял покрытие до 84,6%, но не улучшил итог:

| Показатель | До | После |
| --- | ---: | ---: |
| Доказанные недопрогнозы | 397 | 396 |
| Устранено старых случаев | — | 44 |
| Создано новых случаев | — | 43 |
| Подтверждённый дефицит | 1 530,3 | 1 552,6 |
| Прогноз / продажи без стокаута | 1,2128 | 1,2057 |

Лучший fallback: окно 28 дней, минимум 2 нормальных дня, prior 14. Общий объём
пекарни сохранён, но практически все улучшения компенсируются новыми ошибками,
а крупные ошибки становятся глубже.

## Вывод

Простая замена текущей доли медианной долей дней без стокаута не подходит.
Даже достоверные нормальные дни сильно различаются по спросу, ассортименту и
дню недели. Нормализация является zero-sum: увеличение одного SKU обязательно
забирает объём у другого и создаёт новые стокауты.

Следующий вариант должен быть направленным, а не полной переразметкой долей:

1. сохранять текущую аллокацию для большинства SKU;
2. вводить нижнюю границу только для повторяющихся доказанных недопрогнозов;
3. брать объём только у SKU с устойчивым избыточным запасом в подтверждённые
   дни без стокаута;
4. ограничивать перенос на уровне нескольких процентов общего объёма;
5. отдельно обрабатывать нулевые прогнозы как дефект покрытия.

Текущий эксперимент отклонён для production.
